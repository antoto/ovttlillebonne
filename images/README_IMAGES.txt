IMAGES À FOURNIR — OVTT LILLEBONNE
==================================
Aucune image n'a été générée automatiquement (comme demandé).
Placez simplement vos photos dans ce dossier "images/" en respectant
exactement les noms de fichiers ci-dessous. Le site les affichera
automatiquement.

- logo_ovtt.png        -> Logo du club (utilisé dans le menu et le pied de page). Fond transparent recommandé, carré.
- photo_accueil.jpg    -> Grande photo de VTT pour la bannière de la page d'accueil. Format large (1920x1080 conseillé).
- equipe.jpg           -> Photo d'équipe utilisée sur la page d'accueil et la page À propos.
- competition.jpg      -> Photo de compétition (libre d'utilisation dans le blog/organisations si besoin).
- team_pilote_exemple.jpg  -> Photo d'exemple pour une carte "Pilote" (page Le Team).
- team_staff_exemple.jpg   -> Photo d'exemple pour une carte "Staff" (page Le Team).

FORMAT OBLIGATOIRE DES PHOTOS "LE TEAM" : 800 x 1000 px (portrait),
pour que toutes les cartes pilotes/staff soient parfaitement alignées.

IMAGES DU BLOG ET DES ORGANISATIONS (gérées depuis admin.html)
---------------------------------------------------------------
Ces images ne sont PAS stockées dans ce dossier "images/" : depuis
l'administration, indiquez directement l'URL d'une image hébergée sur
GitHub (ou tout autre hébergeur d'images), par exemple :
https://raw.githubusercontent.com/VOTRE-COMPTE/ovtt-images/main/actu-1.jpg

Si aucune URL n'est renseignée pour un article ou une organisation, le
site utilise une image par défaut également hébergée sur GitHub (voir
la constante GITHUB_ASSETS_BASE en haut de js/main.js — à adapter à
votre propre dépôt d'images).
